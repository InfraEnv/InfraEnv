# User Guide

The maintained v0.2 Alpha guide is [docs/user/README.md](user/README.md). Its [capability matrix](user/status.md) distinguishes tested features from disabled target-state controls.

Quick rule: the general Playground currently runs the host S2 model, while `Find Slow Worker` is the Docker-backed course with a real Ubuntu Shell. Browser PTY, persistent Workspace volumes, external S3 Connector, and generic faults are not connected and must remain disabled.
